# Налаштування Cron-завдань — CoreCommerce

## Архітектура: як це працює

CoreCommerce використовує **дворівневу систему Cron**:

```
ОС (кожну хвилину)
    └── cron_manager.php          ← єдиний запис в crontab ОС
            ├── generate_sitemap.php   → schedule: "0 3 * * *"    (щодня о 03:00)
            ├── check_updates.php      → schedule: "30 4 * * *"   (щодня о 04:30)
            └── prom_sync.php          → schedule: "*/30 * * * *" (кожні 30 хв)
```

**ОС запускає лише один файл** — `cron_manager.php` — кожну хвилину.
Він читає таблицю `cron_tasks` і запускає ті завдання, у яких `next_run <= NOW()`.

**Розклад кожного завдання** (`schedule`) керується через адмінку — без правки crontab на сервері.
Після виконання `cron_manager.php` автоматично розраховує і записує наступний `next_run`.

---

## Крок 1 — Налаштування ОС (робиться один раз)

### Linux / VPS

```bash
crontab -e
```

Додайте **один рядок:**

```cron
* * * * * php /var/www/mysite/cron_manager.php >> /var/www/mysite/storage/logs/cron.log 2>&1
```

> Замініть `/var/www/mysite/` на реальний шлях до проекту.
> Перевірте шлях до PHP: `which php`

### Windows / OSPanel (локально)

1. **Планувальник завдань** (`Win + S` → "Планувальник")
2. **Дія → Створити просте завдання**
3. Назва: `CoreCommerce Cron`
4. Тригер: **Щохвилини**
5. Дія: **Запустити програму**
6. Програма:
   ```
   C:\OSPanel\modules\php\php-8.3\php.exe
   ```
7. Аргументи:
   ```
   C:\OSPanel\home\mysite.test\cron_manager.php
   ```

## Крок 2 — Керування завданнями через адмінку

**Адмінка → Система → Cron-завдання**

Тут ви керуєте розкладом кожного завдання без доступу до сервера:

| Кнопка | Дія |
|--------|-----|
| ✏️ | Змінити назву, розклад, файл |
| Enable / Disable | Увімкнути або призупинити завдання |
| ▶️ | Запустити негайно (не чекаючи розкладу) |
| 🗑 | Видалити завдання |
| **+ Додати завдання** | Створити нове завдання |

---

## Крок 3 — Додавання нового завдання

1. Натисніть **+ Додати завдання**
2. Заповніть форму:

| Поле | Опис | Приклад |
|------|------|---------|
| Назва | Зрозуміла назва | `Генерація Sitemap` |
| Розклад | Cron-рядок (5 частин) | `0 3 * * *` |
| Файл скрипту | Шлях від кореня проекту | `tasks/generate_sitemap.php` |
| Параметри | JSON (необов'язково) | `{"mode": "full"}` |
| Статус | active / disabled | `active` |

---

## Формат Cron-рядка (розклад завдання)

```
┌── хвилина    (0-59)
│ ┌─ година    (0-23)
│ │ ┌ день міс.(1-31)
│ │ │ ┌ місяць (1-12)
│ │ │ │ ┌ день тижня (0-7, де 0 і 7 = неділя)
│ │ │ │ │
* * * * *
```

| Розклад | Коли запускається |
|---------|-------------------|
| `* * * * *` | Кожну хвилину |
| `*/5 * * * *` | Кожні 5 хвилин |
| `*/30 * * * *` | Кожні 30 хвилин |
| `0 * * * *` | Кожну годину |
| `0 3 * * *` | Щодня о 03:00 |
| `30 4 * * *` | Щодня о 04:30 |
| `0 0 1 * *` | 1-го числа місяця о 00:00 |

---

## Завдання які вже є в проекті

| Файл | Призначення | Рекомендований розклад |
|------|-------------|------------------------|
| `tasks/generate_sitemap.php` | Генерація Sitemap XML | `0 3 * * *` |
| `tasks/check_updates.php` | Перевірка оновлень CoreCommerce | `30 4 * * *` |

## Перевірка роботи

### Через адмінку (найпростіше)

1. Адмінка → Система → Cron-завдання
2. Кнопка ▶️ навпроти завдання
3. Колонка **Результат**: `success` = OK, `failed` = помилка (текст поруч)

### Через командний рядок

```bash
# Linux
php /var/www/mysite/cron_manager.php

# Windows OSPanel
C:\OSPanel\modules\php\php-8.3\php.exe C:\OSPanel\home\mysite.test\cron_manager.php
```

### Перегляд логу

```bash
# Linux
tail -f /var/www/mysite/storage/logs/cron.log

# Windows — відкрийте в Notepad++
storage\logs\cron.log
```

---

## Безпека

- `cron_manager.php` повертає **403 Forbidden** при відкритті через браузер
- Task скрипти в `tasks/` теж захищені — відкриваються лише через CLI або `cron_manager.php`
- Управління через адмінку захищене авторизацією адміна + CSRF токеном
